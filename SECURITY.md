# Security policy

Do not commit passwords, API keys, OAuth tokens, local AI provider settings, chat transcripts, project workspaces, or personal/corporate data.

The AI Team application stores local data under `%USERPROFILE%\.ait`. This directory must not be included in the public repository.

If you discover a vulnerability, report it privately to the repository owner using GitHub's private vulnerability reporting feature, when available. Do not publish exploit details or secrets in a public issue.

AI Team invokes third-party CLI tools installed and authenticated separately. Review their permissions and comply with your organization's policies.
